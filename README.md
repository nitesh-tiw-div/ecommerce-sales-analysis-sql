# E-Commerce Sales Analysis using SQL

## 📌 Project Overview

This project is an E-Commerce Sales Analysis database created using MySQL.

The project manages customers, products, orders, order details, reviews, shipping, discounts, and coupons. SQL queries are used to analyze sales performance, customer behavior, product performance, delivery, reviews, and discounts.

## 🛠️ Technologies Used

- MySQL
- SQL
- MySQL Workbench

## 🗄️ Database

Database Name: `EcommerceSalesDB`

### Tables

- Categories
- Products
- Customers
- Orders
- OrderDetails
- Reviews
- Shipping
- Discounts
- Coupons

The database uses primary keys, foreign keys, unique constraints, and relationships to maintain data integrity.

## 📊 Analysis Performed

The project includes SQL queries for:

- Revenue analysis
- Orders by status
- Top-selling products
- Sales by category
- Top customers by orders and revenue
- Average order value
- Largest and smallest orders
- Product sales contribution
- Category sales contribution
- Repeat customers
- Customers with no orders
- Products with no reviews
- Product ratings
- Reviews analysis
- Discount analysis
- Shipping and delivery performance
- Late deliveries
- Customers by city
- Best-selling product in each category
- Top customer in each city
- Average selling price by category
- 2026 customer orders
- Average items per order
- Most reviewed products

## ▶️ How to Run

1. Open MySQL Workbench.
2. Open `ecommerce_sales_analysis-2.sql`.
3. Execute the complete SQL script.
4. The `EcommerceSalesDB` database will be created automatically.
5. Run the analysis queries to view the results.

## 🎯 Project Objective

The main objective of this project is to practice database design and SQL analysis using an e-commerce dataset.

It demonstrates how SQL can be used to manage relational data and generate useful business insights from sales, customers, products, orders, reviews, shipping, and discount information.
